ObjectScratch 扩展编写指南

通过编写 JSON 扩展文件，你可以为 ObjectScratch 添加自定义积木和执行逻辑。

1. 扩展文件结构

扩展是一个 .json 文件，顶层结构如下：

{
  "id": "my-extension",
  "name": "我的扩展",
  "color": "#FF6B6B",
  "blocks": [ ... ],
  "executors": { ... }
}
字段类型说明
idstring扩展唯一标识（英文、短横线），不可与已有分类重复
namestring在面板中显示的分类名称
colorstring积木边框/文字颜色，十六进制颜色值
blocksarray积木定义列表
executorsobject积木类型 → 执行器函数（JS函数字符串）

2. 积木定义

每个积木对象包含以下字段：

字段类型必填说明
typestring是积木类型标识，全局唯一
labelstring是显示文字，{参数名} 表示参数槽
shapestring是形状：stack / reporter / boolean / hat / c-block
paramsarray否参数列表
portsobject否端口配置 { flowIn, flowOut }（自动推断）
subBlocksarray否子代码区域名列表，仅 c-block 使用
code_expobject否代码编程模式下的函数名，如 { "python": "hello", "ALB": "hello", "JavaScript": "hello" }

积木形状说明

形状说明典型用途
stack普通积木，有上下 flow 端口执行动作：移动、打印
hat帽子积木，只有下方 flow事件触发：当程序启动
reporter椭圆积木，无 flow，有值输出返回值：计算、获取属性
boolean菱形积木，无 flow，返回布尔值条件判断：大于、包含
c-blockC 形积木，包含子代码区域循环/条件：重复、如果

参数类型

type说明默认值示例
string文本输入框"hello"
number数字输入框0
dropdown下拉选择，需配合 options"选项A"

3. 执行器函数

执行器是一个 JavaScript 函数字符串，签名为：

function(params, scope) {
  // params: 参数值对象 { param1: value, param2: value }
  // scope: 当前作用域变量
  // 返回值：reporter/boolean 需返回值；stack 无需返回
  // 特殊返回：'__RETURN__' 终止函数；'__STOP__' 终止程序
}

stack 执行器示例（无返回值）

"ext_log": "function(params) { console.log(params.msg); }"

reporter 执行器示例（有返回值）

"ext_add": "function(params) { return Number(params.a) + Number(params.b); }"

boolean 执行器示例（返回布尔值）

"ext_is_even": "function(params) { return Number(params.n) % 2 === 0; }"

3.1 代码编程模式使用（code_exp）

给积木加上非必填属性 code_exp，指定它在三种代码语言中的函数名后，安装该扩展即可在代码编程模式直接调用（打开项目或安装扩展时动态加载 API）：

{
  "id": "h",
  "name": "h",
  "blocks": [
    { "type": "ext_hello", "label": "打招呼", "shape": "stack",
      "code_exp": { "python": "hello", "ALB": "hello", "JavaScript": "hello" } }
  ],
  "executors": { "ext_hello": "function(params, scope) { console.log('hello'); }" }
}
代码模式调用写法
JavaScripth.hello()（以扩展名作为命名空间对象）
Pythonh.hello()
ALB(h_hello)（函数名前加扩展名，用 _ 分隔）

若积木有 params，参数按定义顺序作为位置参数传递：h.add(1, 2) / (h_add 1 2)。没有写 code_exp 的积木也会自动转为通用桥 run_block（见 3.3），仍然能在代码模式调用执行。

3.2 积木多语言标签（labels）

每个积木都可以在注册时内联声明各语言的显示文本，新增语言不需要修改任何 i18n 数据文件：

BlockRegistry.register({
  type: 'ext_hello',
  category: 'h', color: '#8A2BE2',
  label: '打招呼 {name}',                       // 中文基准（写在代码里）
  labels: {                                     // 非中文语言的内联翻译
    en: 'Say hello to {name}',
    // ja: '{name} に挨拶する',                 // 随时可扩展第三种语言
  },
  shape: 'stack', params: [{ name: 'name', type: 'string', default: 'Objector' }],
});

标签解析优先级（BlockRegistry.getLabel）：

顺序来源说明
1getLabel(block)动态标签函数，可用 i18n.L({zh, en}, 兜底)
2labels[当前语言]内联多语言映射，缺当前语言时回退 zh-CN 键
3labelKey走 i18n.t() 查询 src/i18n/*.js 数据表
4label中文原文

语言查找由 i18n.pick(map, fallback) 完成：当前 locale → locale 主语言段（en-US → en）→ zh-CN → fallback，因此只写 en 也能在 en-US 下正确显示。JSON / JS / Python 三种扩展格式同样支持该属性（JSON 写成 "labels": { "en": "..." }）。

3.3 积木代码翻译（code / codeFn）与通用桥

积木可内联注册它在代码模式下等价的三语言写法，把积木拖进代码框时会直接展开：

BlockRegistry.register({
  type: 'ext_add', label: '{a} 加 {b} 的和', shape: 'reporter',
  code: {
    python:     '({a} + {b})',
    javascript: '({a} + {b})',
    alb:        '(+ {a} {b})',
  },
  params: [{ name: 'a', type: 'number', default: 0 }, { name: 'b', type: 'number', default: 0 }],
});

// 需要根据参数动态组织时, 用 codeFn（返回行数组或单个字符串）
BlockRegistry.register({
  type: 'ext_repeat_n', label: '重复 {times} 次做 {what}', shape: 'stack',
  codeFn: (def, lang) => lang === 'python'
    ? ['for _i in range({times}):', '    pass']
    : undefined,   // 返回 undefined 时继续用 code / 通用桥
});
占位符展开结果
{参数名}该语言的字面量：数字原样、字符串加引号、布尔按语言（Python 用 True/False）、number/boolean 型空值用 0
{&参数名}原样插入文本（自己书写表达式）

翻译解析优先级（CodeModeBlocks.toCode(blockType, lang)）：① 内联 code/codeFn → ② 扩展 code_exp → ③ 内置映射表 → ④ 通用桥 run_block → ⑤ 说明注释。

没有注册 code 也没有 code_exp 的积木会自动走通用桥，三语言都能真实执行：

# Python
run_block("mb_led_on", "pattern", "09990")
// JavaScript
run_block("mb_led_on", "pattern", "09990")
; ALB（前缀式变参调用）
(run_block "mb_led_on" "pattern" "09990")

配套可直接调用的运行时 API（三语言同名，由 CodeRuntime 注入）：

分组可用名称
积木run_block(type, key, val, ...)
数学math_abs / floor / ceil / round / sqrt / sign / sin / cos / tan / asin / acos / atan / atan2 / exp / log / log2 / log10 / min / max / clamp / lerp / pi / e
文本str_len / upper / lower / trim / repeat / replace / contains / index_of / letter / sub / of / newline、num_of
积木变量与列表blk_var / blk_set_var、blk_list_len / get / push / insert / set / delete / clear / has / index / join / reverse / sort（索引从 1 开始，与积木一致）
时间与侦测answer / username / timestamp / current_time / format_time / sprite_direction / sprite_size
流程sleep(sec) 阻塞等待、schedule(sec, "代码字符串") 延时执行、stop_all() 停止运行

不可转换的三类积木会生成带说明的注释而不是代码：事件帽积木（hat，代码模式逐帧执行本身就不需要入口）、含子代码槽的积木（c-block / c-block-reporter，请用语言原生循环/条件）、参数中含积木引用（type: 'block'）的积木。

异步回报积木的取值语义：代码模式的 JS/ALB 帧是同步执行的，run_block 对异步积木本帧返回上一帧的完成结果（首帧为空值），副作用仍在调用时立即发生。需要精确等待完成时请改用积木模式或 schedule。

4. JSON 格式完整示例

{
  "id": "math-tools",
  "name": "数学工具",
  "color": "#00BCD4",
  "blocks": [
    {
      "type": "ext_math_square",
      "label": "{n} 的平方",
      "shape": "reporter",
      "params": [
        { "name": "n", "type": "number", "default": 2 }
      ]
    },
    {
      "type": "ext_math_is_even",
      "label": "{n} 是偶数",
      "shape": "boolean",
      "params": [
        { "name": "n", "type": "number", "default": 0 }
      ]
    },
    {
      "type": "ext_log",
      "label": "记录日志 {msg}",
      "shape": "stack",
      "ports": { "flowIn": true, "flowOut": true },
      "params": [
        { "name": "msg", "type": "string", "default": "调试信息" }
      ]
    }
  ],
  "executors": {
    "ext_math_square": "function(params) { var n = Number(params.n); return n * n; }",
    "ext_math_is_even": "function(params) { return Number(params.n) % 2 === 0; }",
    "ext_log": "function(params) { console.log('[LOG]', params.msg); }"
  }
}

5. JavaScript 格式扩展（推荐）

JS 格式允许你直接编写真正的函数，无需字符串转义，更加灵活强大。

JS 格式优势

  • ✅ 直接写函数，不需要字符串转义
  • ✅ 支持多行函数、复杂逻辑
  • ✅ 可以使用闭包、局部变量
  • ✅ 一个文件可以注册多个扩展
  • ✅ 更好的代码可读性

JS 扩展模板

/**
 * JS 扩展示例：游戏工具
 */

ExtensionManager.registerExtension({
  id: 'ext_game',
  name: '游戏工具',
  color: '#A29BFE',
  blocks: [
    {
      type: 'ext_game_score',
      label: '设置分数为 {val}',
      shape: 'stack',
      ports: { flowIn: true, flowOut: true },
      params: [{ name: 'val', type: 'number', default: 0 }],
    },
    {
      type: 'ext_game_get_score',
      label: '当前分数',
      shape: 'reporter',
      ports: { flowIn: false, flowOut: false },
      params: [],
    },
  ],
  executors: {
    // 直接写函数，不需要字符串！
    ext_game_score: function(params) {
      window.__gameScore = Number(params.val);
      console.log('[游戏] 分数设置为', window.__gameScore);
    },
    
    ext_game_get_score: function() {
      return window.__gameScore || 0;
    },
  },
});

// 可以在文件中初始化状态
window.__gameScore = 0;

5.1 Python 格式扩展（.py）

积木执行器也可以用 Python 编写（由内置 Skulpt 解释器执行）。文件以 .py 结尾，在扩展创作模式里新建文件名以 .py 结尾即可得到模板；写代码时先 def 执行函数，最后调用宿主注入的 register_extension({...})（无需 import）。

Python 扩展模板

# 积木执行器用 def 编写, register_extension 必须写在所有 def 之后
# 执行器接收两个 dict: params（积木参数）与 scope（执行上下文）, 返回值即 reporter 结果
def ext_say(params, scope):
    say(params["text"])                      # 直接调用舞台 API
    print("扩展被调用: " + str(params["text"]))

def ext_add(params, scope):
    return params["a"] + params["b"]

register_extension({
    "id": "pydemo",
    "name": "Python 测试扩展",
    "color": "#FF6B6B",
    "blocks": [
        {"type": "ext_say", "label": "说 {text}", "shape": "stack",
         "params": [ {"name": "text", "type": "string", "default": "你好"} ],
         "code_exp": { "python": "say_it", "ALB": "say_it", "JavaScript": "sayIt" }},
        {"type": "ext_add", "label": "{a} 加 {b}", "shape": "reporter",
         "params": [ {"name": "a", "type": "number", "default": 1},
                     {"name": "b", "type": "number", "default": 1} ]},
    ],
    "executors": {
        "ext_say": ext_say,
        "ext_add": ext_add,
    },
})

Python 执行器约定

  • ✅ 执行器签名固定为 def fn(params, scope)，两个参数都是字典（params 为积木输入参数，scope 为执行上下文如循环变量 scope["__i"]）
  • ✅ 可直接调用舞台 API：say / show / hide / move / turn_right / goto_xy / set_x / get_x / key_pressed / mouse_x / set_sprite / set_var / get_var ...
  • ✅ reporter 积木直接 return 值；boolean 积木 return True/False；stack 积木无需 return
  • ✅ print(...) 输出到开发者工具控制台（前缀 [Python 扩展]），报错会带（与源文件一致的）Python 行号
  • ✅ code_exp 属性同样生效，代码编程模式里可按命名空间对象调用（如 h.say_it("你好")）
  • ⚠️ 一个 .py 文件可多次调用 register_extension 注册多个扩展
  • ⚠️ 文件必须使用 UTF-8 编码；字典键必须是字符串
  • ❌ 导出的 HTML / EXE 作品不含 Python 解释器，Python 积木在导出页面中不会运行（导出时会弹窗提醒并跳过），需要网页发布请改用 JS / JSON 扩展
  • ❌ C 型积木的子代码槽在 Python 执行器中无法执行（无法 await）
提示：Python 扩展与 JS 扩展可以混用：同一个项目 extensions/ 目录里 .json / .js / .py 都会被自动加载到扩展可用池。

6. 加载扩展

方式一：手动加载

点击工具栏的 🧩 扩展 按钮，选择 .json / .js / .py 文件即可。

方式二：项目自动加载

将扩展文件放在项目的 extensions/ 目录下，打开项目时会自动加载所有 .json、.js 和 .py 文件。
