# ⚡ Objector 编程模组 - Minecraft Bedrock Add-on

在 Minecraft 游戏内使用可视化积木编程操控世界！

## 📥 安装方法

### 方法一：直接导入
1. 将整个 `objector-mc-addon` 文件夹复制到：
   - **Windows**: `%localappdata%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\behavior_packs\`
   - 重命名文件夹为 `objector-addon`
2. 打开 Minecraft，创建新世界
3. 在"行为包"中找到 `Objector 编程模组`，激活它
4. **重要**: 开启 "实验性游戏" 选项 (Settings → Game → Experiments)
5. 进入世界，输入 `/obj` 开始编程！

### 方法二：打包为 .mcpack
1. 选中 `manifest.json`、`pack_icon.png`、`scripts` 文件夹
2. 压缩为 ZIP
3. 将 `.zip` 后缀改为 `.mcpack`
4. 双击 `.mcpack` 文件，Minecraft 自动导入

## 🎮 使用方法

### 命令列表

| 命令 | 说明 |
|------|------|
| `/obj` | 打开 Objector 编程主菜单 |
| `/obj help` | 查看帮助指南 |
| `/obj list` | 列出所有已保存的程序 |
| `/obj run <名称>` | 运行指定程序 |
| `/obj delete <名称>` | 删除指定程序 |

### 菜单导航

```
/obj → 主菜单
  ├─ 🎯 执行积木 → 选择分类 → 选择积木 → 填写参数 → 执行！
  ├─ 📋 我的程序 → 选择程序 → 运行/编辑/删除
  ├─ 🔨 编写程序 → 编排多个积木 → 保存 → 随时运行
  └─ 📖 帮助 → 查看所有积木说明
```

## 📦 积木分类

### 📦 方块 (5 个)
- **放置方块** - 在指定坐标放置任意方块
- **填充区域** - 用方块填充一个长方体区域
- **替换方块** - 将区域内一种方块替换为另一种
- **清除区域** - 清除区域内所有方块(设为空气)
- **克隆结构** - 复制一个区域到另一个位置

### 🐾 生物 (4 个)
- **生成生物** - 在指定位置生成实体(1-20只)
- **杀死附近实体** - 清除范围内指定类型的实体
- **骑乘实体** - 生成并骑乘动物/载具
- **传送实体** - 将实体传送到指定位置

### 👤 玩家 (6 个)
- **传送玩家** - 传送到指定坐标
- **给予物品** - 获取物品(1-64个)
- **设置游戏模式** - 切换生存/创造/冒险/旁观
- **添加效果** - 获得药水效果
- **设置经验** - 调整经验等级
- **恢复饱食度/生命值** - 快速回满

### 🌍 世界 (5 个)
- **设置时间** - 白天/正午/夜晚/午夜
- **设置天气** - 晴天/雨天/雷暴
- **设置难度** - 和平/简单/普通/困难
- **设置游戏规则** - 死亡不掉落、PvP 等开关
- **设置出生点** - 修改世界出生位置

### 🏗️ 建筑 (5 个)
- **生成墙壁** - 快速建造一面墙
- **生成地板** - 生成方形地板
- **生成简易房屋** - 自动生成带门窗的房屋
- **生成柱子** - 建造垂直柱子
- **生成球体** - 建造近似球体结构

### ✨ 特效 (6 个)
- **爆炸** - 在指定位置引爆(可调威力和引燃)
- **闪电** - 召唤闪电束
- **播放声音** - 播放各种音效
- **显示标题** - 屏幕中央显示大标题
- **动作栏消息** - 底部小字提示
- **广播消息** - 全服公告

### 🔧 逻辑 (5 个)
- **循环执行命令** - 重复执行 MC 命令(可设间隔)
- **延迟执行** - 等待 N 秒后执行
- **随机执行** - 50%概率二选一
- **如果附近有实体** - 条件执行
- **自定义命令** - 输入任意 MC 命令

## ⚠️ 注意事项

1. **必须开启实验性游戏** - Script API 需要此选项
2. **需要操作权限** - 确保你有命令执行权限(op)
3. **程序存储** - 程序保存在世界数据中，每个世界独立
4. **坐标系统** - `~` 表示相对玩家当前位置，如 `~3` = 当前位置+3
5. **基岩版专属** - 此模组仅适用于 Minecraft Bedrock/基岩版 (Windows 10/11, 手机, 主机)

## 📁 文件结构

```
objector-mc-addon/
├── manifest.json          ← Add-on 配置
├── pack_icon.png          ← 图标
└── scripts/
    ├── main.js            ← 入口 + 命令注册
    ├── block-commands.js  ← 36个积木指令定义
    ├── ui-menus.js        ← 游戏内 UI 菜单系统
    └── program-manager.js ← 程序存储/运行管理
```

## 🔧 自定义积木

在 `block-commands.js` 的 `_registerAllBlocks()` 函数中添加新积木：

```javascript
_register('分类ID', '积木ID', '积木名称', [
  { key: '参数名', label: '显示名', type: 'dropdown|text|slider|toggle', ... },
], (params, player) => {
  // 执行逻辑
  _run(player, `命令 ${params.参数名}`);
  return '§a✓ 执行成功提示';
});
```
